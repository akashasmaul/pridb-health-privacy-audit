# Changelog

## [1.0.0] — 2026-07-16

### Added

- PostgreSQL 18 schema with RBAC, RLS, secured views, column grants, and audit triggers.
- Deterministic 1,000-patient synthetic dataset generator.
- k-anonymity, l-diversity, t-closeness, and suppression analysis.
- Laplace differential-privacy query demonstrations and 100-trial evaluation.
- Experimental Privacy Risk Score across eight configurations.
- Sixteen unit tests and twelve internal verification checks.
- Publication-format figures, research documentation, and interactive website.
